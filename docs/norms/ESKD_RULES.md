# Дополнительные правила по основным стандартам ЕСКД (Q01–Q41, S15–S20, O19–O32)

Рабочая справка: какие пункты стандартов контролируют новые правила. Тексты стандартов прочитаны по PDF
(ГОСТ 2.109-73, 2.201-80, 2.301-68, 2.302-68, 2.305-2008, 2.309-73); ГОСТ 2.307-2011, 2.308-2011 и 2.106 — по скану
без текстового слоя, поэтому для них правила составлены по общеизвестным требованиям и **их стоит сверить с
оригиналом** (отмечено «сверить»). Правила Q (модуль `checking/eskd.py`) проверяют текст, основную надпись и рамки
допусков; геометрия (толщины линий, стрелки, штриховка) не анализируется. Сомнительные правила выключены по умолчанию.

Условные обозначения: «выкл.» — выключено по умолчанию (включается в панели «Проверки по стандартам»).

## Ограничения
* Все правила работают по тексту чертежа: если текст набран кривыми или распознан OCR с ошибками, они молчат или
  ошибаются.
* Правила Q13/Q14 и Q18 зависят от распознавания размеров и номеров позиций; Q33 — от распознавания знаков Ⓜ, Ⓟ.
* Не проверяются: толщины и типы линий, стрелки, штриховка, положение размеров (кроме D31–D33), оформление таблиц
  на поле чертежа, электронные модели.
* Проверено на 33 PDF из `samples/`: сбоев нет; из шумных наблюдений выключены по умолчанию Q15, Q25, Q30, Q31, Q41.
