# Сварные швы (Y01–Y08) и ГОСТ 6033, 6357, 6636, 8724, 9013, 10948, 11284, 14034 (U01–U08)

## Сварные швы: типы соединений (ГОСТ 5264-80, 14771-76 табл. 1)
Буква обозначения задаёт тип: **С** — стыковое, **У** — угловое, **Т** — тавровое, **Н** — нахлёсточное
(ГОСТ 14098 — ещё **К**, крестовое). Номер задаёт разделку кромок, число сторон шва и диапазон толщин.
Геометрию узла программа не видит, поэтому «конструктор заложил угловой, а написан тавровый» ловится по тому, что
написано рядом с обозначением и в ТТ, а также по признакам, которые следуют из типа (катет, способ сварки, толщина).

| Правило | Что проверяет |
|---|---|
| W02, W05 (ранее) | номер соединения есть в стандарте; стандарт шва совпадает с ТТ |
| J25, J26 (ранее) | у У/Т/Н есть катет; у С катета нет |
| Y01 | слово рядом с обозначением («стыковой», «угловой», «тавровый», «нахлёсточный») совпадает с буквой типа |
| Y02 | то же в ТТ: «Швы У4 — стыковые» |
| Y03 | по ГОСТ 5264 (ручная сварка) способа сварки в обозначении нет |
| Y04 | по ГОСТ 14771 способ сварки указан и из списка ИН, ИНп, ИП, УП |
| Y05 (выкл.) | толщина детали входит в диапазон соединения по ГОСТ 5264 (табл. 1) |
| Y06 | чертёж «сварной» (название, ТТ), а обозначений швов нет |
| Y07 | швы по разным стандартам без пояснения в ТТ |
| Y08 | «К» вместе с ГОСТ 5264/14771/8713 |

Источник таблиц — распознанный текст табл. 1 ГОСТ 5264-80 и 14771-76 (meganorm.ru): колонки для части строк
сдвинуты, поэтому диапазоны толщин Y05 взяты только для однозначно прочитанных соединений и правило выключено;
перед включением сверьте таблицу `RANGE_5264` в `checking/welds2.py` с оригиналом. Допустимые способы сварки
(ИН, ИНп, ИП, УП) — п. 2 ГОСТ 14771-76.

Не покрыто: ГОСТ 8713, 11534, 11533, 23518, 14776 проверяются только на диапазон номеров (W02).
Определить тип соединения по чертежу (сопряжение листов, угол, сторона шва) можно только по графике — это
следующий шаг, если нужна проверка по самому изображению.

## ГОСТ 6033, 6357, 6636, 8724, 9013, 10948, 11284, 14034
| Правило | Стандарт | Что проверяет |
|---|---|---|
| U01 | 8724, 2.311 | шаг отделён знаком «×», а не буквой x/х |
| U02 | 6357 | трубная резьба — «G», а не «трубная 1/2"» |
| U03 | 6357 | перед G знак ⌀ не ставят |
| U04 | 9013 | HRC в пределах 20…70 |
| U05 (выкл.) | 10948 | радиусы 10…500 мм из ряда |
| U06 (выкл.) | 11284 | «N отв. ⌀X» близко к стандартному отверстию под крепёж |
| U07 | 14034 | у центровых отверстий форма и размер |
| U08 (выкл.) | 6636 | диаметры свыше 10 мм из ряда Ra40 |

Ранее эти стандарты контролировали K04 (6033), D25 (6357), D11 (6636), D15/D26 (8724), D23 (8908), H02 (9013),
Z01/Z07 (9563), D17/D29 (10948), K01 (14034). Тексты самих стандартов найти не удалось, правила составлены по
общеизвестным требованиям; ряды (U05, U08) и граница 20 HRC (U04) подлежат сверке с оригиналом.
