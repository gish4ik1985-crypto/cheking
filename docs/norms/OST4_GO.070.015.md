# ОСТ 4 ГО.070.015 — Сборочные единицы радиоэлектронной аппаратуры. Общие технические условия

Рабочая справка (редакция 2-75, введён 01.07.1976, группа Г10; взамен ред. 1-70; переиздание 1992 с изм. 3–5).
Это пересказ требований с номерами пунктов, а не полный текст; источник — скриншоты из базы «Кодекс».
Парный стандарт для деталей — [ОСТ4 ГО.070.014](OST4_GO.070.014.md).

**Область применения.** Сборочные единицы, изготавливаемые на предприятиях отрасли и применяемые в изделиях,
поставляемых потребителю, кроме единиц, на которые есть другие НТД. Действует при наличии ссылки на чертеже.
Запись: «Технические требования по ОСТ 4 ГО.070.015»; при других требованиях — «Остальные технические
требования — по ОСТ 4 ГО.070.015».

Ссылочные НТД: ГОСТ 15150-69 (п. 5.1), ОСТ 4 Г0.070.014 ред. 2-75 (п. 1.1), РД 107.9.4002-88 (п. 2.7).

## 1. Общие требования

| П. | Требование | Проверка по чертежу |
|---|---|---|
| 1.1 | Сборочные единицы, подвергающиеся механической обработке при сборке, и детали без чертежа — по ОСТ4 ГО.070.014 | нет |
| 1.2 | Материалы и изделия внешних поставщиков — по чертежам, стандартам и ТУ, со штампом ОТК (малогабаритные — паспорт) | нет |
| 1.3 | Покупные изделия для приёмки заказчиком — с клеймом/штампом приёмки; для входного контроля — отметка о проверке | нет |
| 1.4 | Детали и сборочные единицы расконсервированы и очищены или промыты | нет |
| 1.5 | При сборке не допускаются механические повреждения деталей и сборочных единиц | нет |
| 1.6 | Не допускается нарушение антикоррозионных и декоративных покрытий; допустимо частичное нарушение плёнок (хроматной, оксидной) в местах приложения инструмента и на трущихся поверхностях. Дополнительная защита лаками/эмалями указывается в чертеже или ТУ | нет |
| 1.7 | Недопустимо попадание в сборочные единицы стружки, опилок, ворса и случайных частиц | нет |
| 1.8 | Резиновые и войлочные прокладки выровнены по краям, плотно сидят в пазах, без трещин и складок | нет |

## 2. Неподвижные соединения

| П. | Требование | Проверка по чертежу |
|---|---|---|
| 2.1 | В неразъёмных соединениях (заклёпочных, прессовых) нет качки и проворачивания | нет |
| 2.2 | Крепёжные резьбовые соединения затянуты плотно и равномерно | нет |
| 2.3 | Шлицы в головках винтов, грани головок болтов и гаек не сорваны и не смяты | нет |
| 2.4 | Резьба предохраняется от лакокрасочного покрытия; допустимо попадание краски на один виток, если не нарушается свинчиваемость | нет |
| 2.5 | Заклёпки плотно стягивают детали, головки правильной формы, без заусенцев; в зоне двух диаметров головки зазора нет; потайные головки зачищены заподлицо до покраски; вмятины вокруг головок не глубже 0,2 мм и в пределах окружности трёх диаметров головки | нет |
| 2.6 | Пустотелые и полупустотелые заклёпки, втулки и другие развальцовываемые детали — не более двух радиальных разрывов, без заусенцев | нет |
| 2.7 | Места клёпки, развальцовки и расчеканки покрывают лаком АК-113 или другим бесцветным лаком по РД 107.9.4002 | **O03** (ТТ упоминает клёпку, лака нет) |
| 2.8 | На деталях из изоляционных материалов (гетинакс, текстолит, карболит) в местах развальцовки, расклёпки, осадки не допускаются сколы и расслоения; допустимы осветлённые участки до 1 мм | нет |

## 3. Подвижные соединения

3.1 откидные, выдвижные и съёмные части свободно откидываются, выдвигаются, снимаются и устанавливаются,
крепёжные соединения совпадают; 3.2 подвижные части (каретки, ползуны) перемещаются плавно, без заеданий и
перекосов; допустимо засветление цинкового, кадмиевого, оксидного и анодного покрытий и почернение поверхностей
после многократного выдвижения; 3.3 детали, передающие движение (валики, маховички, рукоятки, звёздочки,
зубчатые колёса), вращаются плавно; 3.4 стопорные устройства чётко фиксируют положение; 3.5 ручки на осях не
проворачиваются и не качаются; 3.6 стопорящие устройства (цанги, зажимы, пружины, винты) обеспечивают
неподвижное положение; 3.7 подвижные дисковые шкалы свободно проворачиваются при отпущенных зажимах, трение визира
о шкалу не допускается. Все пункты раздела — функциональные, по чертежу не проверяются.

## 4. Правила приёмки

4.1 Все готовые сборочные единицы проверяет ОТК предприятия-изготовителя. 4.2 При самостоятельной поставке
потребитель вправе проверять качество; без ТУ отбирают 5 % образцов, но не менее 5 шт. каждого типоразмера.
4.3 При несоответствии — повторная проверка удвоенного количества единиц из той же партии; если снова брак —
вся партия возвращается изготовителю. 4.4 Исправимые дефекты — возврат на исправление и повторное предъявление,
неисправимые — в изолятор брака.

## 5. Методы испытаний

5.1 В нормальных климатических условиях по ГОСТ 15150. 5.2 Пункты 1.1, 1.4–1.8, 2.3–2.8, 3.2 — внешним осмотром,
сличением с чертежами и измерением размеров любым мерительным инструментом. 5.3 Пункты 1.2, 1.3 — сличением с
требованиями стандартов, ТУ и по ярлыкам, сертификатам, документам поставки. 5.4 Пункты 2.1, 2.2, 3.1–3.7 —
опробованием.
