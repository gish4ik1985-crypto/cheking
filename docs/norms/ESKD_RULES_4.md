# Пакетные правила по ГОСТ 6033, 6357, 6636, 8724, 8908, 9013, 9563, 10948, 11284, 14034, 14771, 16093, 23360, 24643, 24738, 25346, 25347, 30893.1, 30893.2 и ГОСТ Р 2.104

Коды из буквы и трёх цифр. Описание каждого правила — в панели администратора (что проверяет, как находит, пример, когда пропускает) и в `checking/ext_*.py` рядом с проверкой.
Правила, помеченные «выкл.», по умолчанию не работают: они справочные или зависят от решения конструктора.

Ограничение: правила работают по тексту, размерам, ТТ, таблице зубчатого венца и рамкам допусков. Геометрию (форма шва, углы, разрезы) программа не видит.
