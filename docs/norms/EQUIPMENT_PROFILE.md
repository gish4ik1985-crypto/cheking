# Профиль оборудования и правила «Возможности производства» (T401–T407)

Сделано 19.10.2026 в `Checking_ui`. Правила не из ГОСТ: они сверяют чертёж с тем, что предприятие умеет делать.

## Данные
* `checking/equipment_data.py` — снимок списка оборудования из ERP (`erp-yarst/database/seeders/EquipmentTableSeeder.php`, 104 единицы).
* `checking/equipment.py` — вид оборудования по названию типа, параметры по обозначению модели, профиль (`Profile`), очистка списка от интерфейса.
* Хранится в `config.json → "equipment": {"items": [...]}`; пока пусто — используется перечень из ERP. «Вернуть перечень ERP» сбрасывает правки.
* Параметр с источником: `model` (по обозначению модели), `type` (из названия типа), `estimate` (ориентир), `passport` (по паспорту), `manual`.
  Всё, кроме `passport`, нужно уточнить по паспорту станка. Незаданный параметр правила не используют (молчат).

## Что выводится из обозначения модели
| Станки | Правило |
|---|---|
| токарные 16К20, 16К25 | две последние цифры — высота центров /10; Ø над станиной = 2 × высота центров |
| токарные 1К62, 1В62, 1М63, 1М65 | размер 2–5 → высота центров 200 / 315 / 400 / 500 мм |
| сверлильные 2Н135, 2А125, 2С132, 2М112 | две последние цифры — наибольший Ø сверления; 2М55 — 50 мм |
| фрезерные 6Р12/13, 6М12П, 6Т82/83, ВМ127 | размер 2 — стол 320×1250, размер 3 — 400×1600 |
| зубофрезерные 5К32, 5Е32 / 53А50 | Ø колеса 320 / 500 мм |
| плоскошлифовальные 3Г71 | стол 630×200 |
| горизонтально-расточные 2620 / 2А614 | Ø шпинделя 90 / 110 мм |
| лазеры (SF6015, USI-3015) | поле = две пары цифр × 100 мм (проверить); мощность — из названия типа («20кW»). LM3512HGP — 12 000×3000 мм по сообщению заказчика (не по формуле: «3512» даёт неверный результат) |
| вальцы ST2500*20 | ширина 2500, толщина 20 мм |
| лазерный труборез SF6035T | длина 6000, Ø до 350 мм |

Предельная толщина лазера по мощности — таблица `LASER_THICKNESS` в `equipment.py` (ориентир по данным производителей, не паспорт):
1,5 кВт — сталь 8 / нержавейка 4 / алюминий 3 мм; 6 кВт — 20 / 16 / 12; 20 кВт — 40 / 30 / 25.

## Правила (группа `capab`, блок «Технологичность конструкции», по умолчанию выключен)
| Код | Что | Важность |
|---|---|---|
| T401 | габарит заготовки листовой детали помещается на стол лазера (с поворотом на 90°) | предупреждение |
| T402 | толщина листа не больше предельной у лучшего лазера для материала (сталь, нержавейка, алюминий) | предупреждение |
| T403 | Ø точёной детали не больше диаметра обработки токарных станков; если у станка Ø не задан, молчит | предупреждение |
| T404 | делительный Ø колеса не больше Ø на зубообрабатывающих станках, либо таких станков нет | предупреждение |
| T405 | IT4 и точнее / Ra ≤ 0,1: нужна доводка, притирочных и хонинговальных станков нет | замечание |
| T406 | термообработка в ТТ (закалка, цементация…) при отсутствии печей / ТВЧ | предупреждение |
| T407 | электроэрозия, лазерная сварка, зубошлифование, гальванические покрытия без оборудования в профиле | замечание |

Габариты берутся из `rules._overall` (оценка по размерным числам, не по картинке); длина считается по наибольшему размеру, ширина — по меньшей стороне
(занижение безопаснее ложного срабатывания). Если нужных данных нет, правило молчит.

## API (администратор)
`GET /api/admin/equipment`, `POST /api/admin/equipment` (весь список), `POST /api/admin/equipment/preview` (как программа разберёт новую запись),
`POST /api/admin/equipment/reset`. Вкладка «Настройки → Оборудование» (`frontend/src/pages/admin/EquipmentTab.tsx`).
