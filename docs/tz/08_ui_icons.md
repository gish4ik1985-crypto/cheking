# 08. Интерфейс и пиктограммы

## 1. Основные экраны

| Экран | Назначение |
|---|---|
| Дерево изделий | Папки, компоненты, документы, поиск и фильтры, быстрые действия по контекстному меню |
| Карточка компонента | Атрибуты, документы, состав, где используется, версии, история изменений |
| Карточка документа | Атрибуты, версии, файлы и вторичные представления, подписи, замечания автопроверки |
| Просмотр | PDF и 3D в браузере, наложение замечаний, сравнение версий |
| Извещение об изменении | Состав, содержание, влияние на родителей, результаты автопроверки, согласование |
| Входящие задания | Задания на согласование, возврат на доработку, делегирование |
| Что в работе | Взятые в работу объекты, блокировки, варианты |
| Администрирование | Типы, атрибуты, нумераторы, справочники, правила взаимосвязи, шаблоны процессов, права, значки |

## 2. Правила интерфейса

- Дерево показывает состав в порядке из части 02: у сборочной единицы спецификация, 3D-модель, сборочный чертёж, затем вложенное; у детали 3D-модель, чертёж, затем остальное.
- Состояние версии виден по значку состояния рядом с объектом (значки состояний утверждаются отдельно).
- Цвет никогда не единственный признак: форма значка и подпись дублируют смысл.
- Светлая и тёмная темы поддерживаются, значки имеют оба варианта цвета.
- Действия, которые меняют данные, требуют подтверждения при необратимости, в остальных случаях доступна отмена.
- Любая блокировка объекта показывает владельца и время.

| № | Требование |
|---|---|
| UI-01 | Экраны из таблицы раздела 1 с общей навигацией и быстрым поиском. |
| UI-02 | Единые пиктограммы по разделу 3 во всех представлениях: дерево, карточка, список документов, состав извещения, отчёты. |
| UI-03 | Значки и их цвета берутся из справочника типов (DOC-01), а не прописываются в коде. |
| UI-04 | Светлая и тёмная темы, адаптация под ширину окна. |
| UI-05 | Значки статусов и версий (действует, проектирование, архив, аннулирован) определить отдельно. |

## 3. Пиктограммы объектов

Утверждены два представления: плашка 36×36 px (карточки, заголовки, списки) и значок 16 px без плашки (дерево состава). Источник значков: библиотека Tabler Icons, контурный стиль (лицензия MIT). Двутавр и фреза нарисованы вручную и хранятся как SVG-файлы. Цвет и форма несут смысл: цвет показывает вид объекта, форма показывает, компонент это или документ.

Принципы:
- Компоненты (сборочная единица, деталь) имеют песочно-оранжевую плашку. Их 3D-модели используют те же формы, но чёрно-белые.
- Документы с разным назначением имеют разные цвета. Одинаковый цвет допустим только у сборочной единицы и детали, так как оба объекта компоненты. У остальных объектов цвета разные, в том числе у маршрутной карты и техпроцесса.
- Чертёж детали и сборочный чертёж различаются и формой, и цветом.
- Справочные записи (материал, сортамент) имеют круглую плашку.

Вложенные элементы техпроцесса (бирюзовая гамма): переход (стрелка вправо, `ti-arrow-narrow-right`), установ (замок, `ti-lock`), позиция (сетка, `ti-layout-grid`), оборудование (двигатель, `ti-engine`), приспособление и оснастка (пазл, `ti-puzzle`), режущий инструмент (ножницы, `ti-scissors`), измерительный инструмент (датчик, `ti-gauge`), вспомогательный инструмент (инструменты, `ti-tools`), материалы: СОЖ, припой, электроды (колба, `ti-flask`), режимы обработки (ползунки, `ti-adjustments-horizontal`), нормы времени (секундомер, `ti-stopwatch`), профессия и разряд (человек с галочкой, `ti-user-check`), программа ЧПУ (код, `ti-code`), операционный эскиз (картинка, `ti-photo`), требования безопасности (щит с галочкой, `ti-shield-check`), технологические указания (заметки, `ti-notes`).

Вложенные элементы маршрутной карты (розовая гамма): маршрут (линия времени, `ti-timeline`), цех и участок (завод, `ti-building-factory-2`), заготовка (посылка, `ti-package`), материалы и комплектующие на изделие (список с подробностями, `ti-list-details`), транспортировка и склад (грузовик, `ti-truck`), исполнитель и разряд (человек с галочкой, `ti-user-check`), норма времени (секундомер, `ti-stopwatch`), примечание (лист с текстом, `ti-file-text`).

Имена значков проверены на наличие в шрифте Tabler Icons Webfont 3.19.0. Значков `ti-drill`, `ti-wrench`, `ti-spanner` в нём нет, они заменены. При смене версии шрифта проверку повторить. Перечень элементов ТП и МК собран по общему представлению о ЕСТД и должен быть сверен с ГОСТ 3.1102 и 3.1118.

Для остальных типов из части 02 (ведомости, ТУ, РЭ, ПС, ФО, ЗИП и др.) значки ещё не утверждены. Пока используется значок группы: группы «Сопроводительные», «Эксплуатационные» и т.д. получают отдельный цвет, отличный от перечисленных выше.

Порядок в дереве компонента: у сборочной единицы спецификация, 3D-модель, сборочный чертёж, затем вложенные компоненты и остальные документы по группам. У детали 3D-модель, чертёж детали, затем остальные документы.
