# Мнения экспертов по правилам

## Для эксперта

«Настройки» → «Проверки по стандартам» → у нужной проверки значок **i** → в конце блока описания поле
**«Мнение эксперта»**. Напишите, что и как должна проверять эта проверка и как на неё реагировать: какие случаи
добавить или исключить, какой должна быть важность (ошибка / предупреждение / замечание), как сформулировать замечание.
Нажмите «Отправить мнение».

* Мнение сохраняется с вашим именем, временем, ревизией правила и версией программы.
* Пока мнение не разобрано, его можно удалить (×).
* Когда разработчик разберёт мнение, под ним появятся статус и ответ: **принято** (правило будет изменено),
  **отклонено** (с объяснением) или **учтено** (правило изменено, указана новая ревизия).
* Кнопка-фильтр «С мнением» показывает только проверки, по которым есть мнения; на значке **i** — число мнений.
* Мнения хранятся в `feedback/expert_notes.json` и попадают в выгрузку «Выгрузить для разработки (ZIP)».

Мнение — это предложение, а не команда: разработчик перепроверит его по тексту стандарта и коду правила.

## Для разработчика

```
python tools/expert_notes.py              # неразобранные: правило, как оно работает сейчас, мнение
python tools/expert_notes.py --all        # все со статусами
python tools/expert_notes.py reply ID applied "Что проверено и что сделано" --rev 2
python tools/expert_notes.py reply ID rejected "Почему не принято"
python tools/expert_notes.py reply ID accepted "Что будет сделано"
```

Порядок разбора:

1. **Перепроверить.** Сверить мнение с текстом стандарта (`docs/norms/`) и кодом правила; убедиться, что это не частный
   случай одного чертежа. Если стандарт не подтверждает — `rejected` с объяснением.
2. **Изменить правило**, если мнение принято: код проверки, текст замечания (с учётом `docs/MIGRATION.md`: тексты существующих
   замечаний меняют только вместе с ревизией), описание в `checking/rule_docs.py`, тесты.
3. **Увеличить ревизию** `REV["КОД"]` в `checking/rule_docs.py`, чтобы отметки тестировщиков по прежнему поведению не
   засчитывались новому.
4. **Ответить** на мнение командой `reply … applied … --rev N`.

Файл с мнениями эксперта нужно получать с той машины, где его вводили: из папки программы (`feedback/expert_notes.json`)
или из ZIP-выгрузки.
